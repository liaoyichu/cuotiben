# 错题本 · 整理小工具

一个打开就能用的错题整理工具。不需要安装、不需要注册，数据也不会上传到任何服务器。

**在线使用**：打开 https://liaoyichu.github.io/cuotiben/ 即可（手机、电脑都可以）。

## 功能

- 📷 **录入错题**：拍照或从相册选图（一道题可存多张：题目、孩子答案、老师批改），自动压缩、提亮，也可以只写文字
- 🗂 **整理筛选**：按科目、知识点标签、待复习/已掌握筛选，支持全文搜索
- 🔁 **复习模式**：盖住答案让孩子重做，做完对照解析，选「做对了 / 又错了」；连续 2 次做对自动标记为已掌握
- 🖨 **打印重做卷**：生成 A4 错题卷，可只印题目（留白给孩子重做）或带答案解析，也能在打印对话框里「另存为 PDF」
- 💾 **备份**：导出 / 导入 JSON 文件，换设备或清理浏览器前先导出

## 数据保存在哪

所有错题**只保存在使用者自己设备的浏览器里**（IndexedDB），不经过任何服务器、不上传、不联网同步。换设备请用「备份 → 导出」把 .json 文件带过去，在新设备「导入」。

## 技术说明

单文件纯前端应用（`index.html`），零依赖、零构建、无后端。图片在上传时会自动缩放到长边 1800px 并做一次对比度拉伸（改善拍照偏灰）。

## 本地运行

```bash
python3 -m http.server 8765
# 然后打开 http://127.0.0.1:8765/
```
